### ML Level-1 Graduation Project: "useage prediction"

transformers can reliably predict the next word given the context

I want to reframe the question to -> is a word in a given context correct.

Using this we can create a stream of changing texts with the same meaning but fluctuating use of words - the function of this model.

This model generates multiple sentences, and interchanges correct context for different words, 

this then feeds into training of contexts for other words, assuming that the meaning is unchanged, words can learn more "meaning" out of equivalent classes in the same context.
